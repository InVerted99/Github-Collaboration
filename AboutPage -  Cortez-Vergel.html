What This Repo Is For

We use this repository to practice the everyday Git workflow: branching off main, opening pull requests, reviewing each other's code, resolving merge conflicts, and keeping a clean commit history.

Our Workflow

1. BranchOne feature, one branch.
2. CommitSmall, clear messages.
3. Pull RequestEvery change gets reviewed.
4. MergeApproved code lands on main.
